WHY

政企服务的智能问答，难在哪？

通用聊天机器人回答不了政企场景的真问题——答案必须有据可查，办事必须一步理清，数据必须不出内网。

📄

大段文字，群众找不到重点

"带什么材料、去哪办、多久办好"埋在几百字政策文本里，看完还是一头雾水，窗口咨询电话被打爆。

我们的解法：六类结构化卡片直出，流程、材料、地点、时限、电话一屏集齐。
🔗

一件事牵涉多个部门，问不全

"开个饭馆要办什么手续"横跨工商、食药监、税务、社保，传统问答只能搜到单个事项的片段。

我们的解法：GraphRAG 多跳推理，沿业务关系链路自动串联全流程。
🗣️

群众说大白话，系统听不懂

"社保卡丢了咋办"——是补办？挂失？还是缴费？口语问法千变万化，关键词匹配频频答错或答非所问。

我们的解法：查询改写 + 意图消歧，十几种说法精准命中同一事项。
CORE TECHNOLOGY

五大核心技术能力

不是套壳聊天机器人，而是围绕政企真实业务流程深度定制的智能服务引擎。

01
🕸️

GraphRAG 图谱融合推理引擎

不是"搜一段文字"，而是"理一条链路"

将 400+ 实体节点、近 500 条业务关系的政务知识图谱，与向量检索、Rerank 精排、大模型推理深度融合：先在图谱中定位事项与实体，再沿关系边做多跳遍历，最后由大模型组织成结构化答案。

  • 多跳链路推理：问"开个小饭馆要办什么手续"，自动串联个体户注册 → 食品经营许可 → 税务登记 → 社保登记全流程，一次问全、一步答全
  • 置信度门控：图谱命中低于阈值自动降级 RAG 向量问答兜底，无依据不抢答、不确定不硬答
  • 轻量化存储：图谱基于 PostgreSQL + JSONB 邻接表实现，不引入 Neo4j 等重型图数据库，私有化部署轻量易维护
02
🎯

听得懂大白话的意图引擎

群众怎么说，系统都能懂
  • 查询改写：大模型自动把口语转成规范问法，"社保卡丢了咋办" → 社会保障卡补换
  • 意图消歧：补办 ≠ 缴费 ≠ 转移，同一实体下的不同事项精准分流，互不误伤
  • 别名网络：一个事项十几种说法都能命中；闲聊、写作、追问场景不误触发图谱
03
🗂️

六类结构化卡片答案引擎

告别大段文字，答案即界面
  • 流程卡：步骤编号 + 责任部门 + 办理时长
  • 材料卡：按事项拆分，必备材料清单一目了然
  • 信息网格卡：办理地点 / 时限 / 费用 / 咨询电话一屏集齐
  • 对比卡：两类事项逐项 PK，差异自动高亮
  • 政策卡 / 智能追问卡：政策要点直出，信息不全主动追问
04
🔌

知识可插拔，行业可复制

数据驱动，零硬编码
  • 办事事项、材料清单、口语别名、流程链路全部标准数据文件驱动，不写死在代码里
  • 业务人员维护数据即生效；换一个行业，只需换一套知识库
  • LLM 自动抽取实体关系 + 管理员审核入图的自动构图能力已在演进路线上
05
🔒

全链路私有化，数据不出域

云端演示与内网私有化，改配置不改代码
  • Docker 一键部署，PostgreSQL + pgvector 单一数据底座，向量、会话、知识库、日志统一存储
  • LLM / Embedding / Rerank 全走配置：云端 MiniMax、DeepSeek 与内网本地模型一键切换
  • 超管 / 管理员 / 访客三级权限、操作可审计、IP 限流与安全防护，满足"数据不出网、权限可管控"

DEPLOYMENT

两种部署形态，按需选择

先云端验证价值，再私有化落地——同一套代码，仅改配置即可切换。

☁️ 云端体验版（SaaS）

开箱即用，无需任何部署，适合快速验证、演示汇报与小范围试用。

  • 访问网址即刻使用，支持桌面端与移动端浏览器
  • 功能与私有化版同源，演示数据可按行业替换
  • 持续迭代升级，始终使用最新版本

🛡️ 私有化部署版 政企推荐

整套系统部署于客户内网，数据不出域，满足政务与行业客户安全合规要求。

  • Docker 一键部署，PostgreSQL + pgvector 统一数据底座，运维轻量
  • 大模型、向量模型、重排模型全部可替换为内网本地模型
  • 三级权限体系、操作审计、限流防护，等保合规项持续完善
  • 知识库由客户自主掌控、随时更新，不依赖厂商硬编码
